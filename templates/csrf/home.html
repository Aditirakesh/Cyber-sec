How to demonstrate the cross-site request

  1. Open this application at http://localhost:5000 and keep the session active.
  2. Open the attacker page using http://127.0.0.1:5000/csrf/attacker/vuln.
  3. The auto-submitting form sends a POST to the localhost vulnerable endpoint. Return to the home page and observe the reduced balance.
  4. Reset the wallet, then open http://127.0.0.1:5000/csrf/attacker/fixed. The same forged POST is rejected because it lacks the synchronizer token.
Run only on localhost. The app configures its session cookie as SameSite=None; Secure for this controlled browser demonstration. Use localhost as the legitimate site, and 127.0.0.1 as the separate attacker origin.
