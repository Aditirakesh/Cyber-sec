Cross-Site Scripting (Reflected XSS)

READY

Variant: Reflected XSS via unencoded search query parameters in the Campus Resource Search Portal.

Vulnerable Search Portal VULN
Output rendered without escaping using Jinja2's |safe filter. Injected JavaScript executes immediately.
Secure Search Portal FIXED
Framework auto-escaping enabled (default Jinja2 behavior). Special characters are safely converted to HTML entities.

Payload to Try

<script>alert('Reflected XSS')</script>

Submit this payload into the search bar. On the vulnerable endpoint, the browser executes the script and triggers an alert box. On the secure endpoint, it is rendered as inert plain text with zero execution.

Demonstration Workflow

  1. Open the Vulnerable Search Portal and search for a normal topic like Python or DSA.
  2. Submit the payload <script>alert('Reflected XSS')</script> and observe the browser popup alert.
  3. Switch to the Secure Search Portal and submit the exact same payload.
  4. Observe that the payload renders harmlessly as literal text on the screen without triggering any alert.
